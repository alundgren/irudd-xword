---
name: morning-crosswords
description: Construct and proofread a Swedish full-page bildkryss and short commute edition in irudd-xword, including private fills, generated pictures, saved feedback and WebKit render checks.
---

Run from the irudd-xword repository. Keep private drafts under ignored `local/`. Read `bun run xword context --lang sv` privately for prior answers and free-text feedback. Check the intended calendar date in Stockholm.

1. Pick two distinct themes and generate original PNG artwork with a clear subject. The full page is 17×19, the train grid 8×10. Seven letters is a practical length for either picture answer. Prepare a ranked Swedish word list, one word per line. The solver adds the bundled curated bank. For an optional local vocabulary, use `uv run --with wordfreq python -c "from wordfreq import top_n_list; print('\n'.join(w for w in top_n_list('sv',18000) if len(w)>=4))" > local/ranked.txt`. Keep external vocabulary local and check its license before redistribution.
2. Draft with `bun run xword draft large --answer WORD --image large.png --words local/ranked.txt --output local/large.json --seed 42`. Repeat with `train`, its own theme and a different seed. Image paths are relative to the output pack. Inspect the entire fill privately. Write bad entries one per line in a file, pass it with `--avoid`, and draft to a fresh path. Drop machine-like abbreviations, inappropriate words and unfamiliar names that only fit the letters. A new seed changes the connections between sections.
3. Edit the pack directly. Give each missing answer a short original clue, review inherited clues for grammar and repetition, and write the picture clue for the visible subject. Check tense, plural, definiteness and homonyms. Mix direct clues with a few fair jokes. Keep the train clues brisk. Set `title` and `edition_day`. Use `bun run xword inspect local/large.json` to check structure and report page occupancy, crossings and missing clues without printing the key.
4. Stage in a temporary collection using `XWORD_DATA=/path/to/staging bun run xword generate --pack local/large.json`. Start the player against that collection and use `bun run render:check ID --port PORT`. Inspect the full-size screenshot and the train puzzle at 390px. Check that every word has useful crossing letters, illustrations fit their reserved area and split clues remain legible. Trim and restage where needed. The full render procedure and construction references are in `AUTHORING.md`.
5. Publish the reviewed packs to the user's local collection with `bun run xword generate --pack PATH` and verify each saved edition through its player link. Give the solver the date, sizes and links. Keep the answer lists, private packs and progress out of chat and source control.
